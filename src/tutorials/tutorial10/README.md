## Run the companion notebook

Extract `student.zip` and run from its folder with Python 3.10+:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab pytorch_intro_tutorial.ipynb
```
