A 25-slide English Beamer walkthrough paired with an executable Jupyter notebook (`transformer_tutorial.ipynb`) containing 18 code cells, 6 figures, PyTorch Self-Attention and Vision Transformer implementations, a multi-step ReAct tool-calling agent, Hugging Face `transformers` workflows, a full-course synthesis table, and recommended Stanford/Berkeley open courses.

## Run the companion notebook

Extract `student.zip` and run from its folder with Python 3.10+:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab transformer_tutorial.ipynb
```
