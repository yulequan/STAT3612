# STAT3612 · Fall 2026 · Tutorial 09

**Unsupervised Learning: Dimensionality Reduction and Clustering**

Tutor: Yinghao Zhu · yhzhu99@connect.hku.hk

A 24-slide English Beamer walkthrough paired with an executable Jupyter notebook (`unsupervised_learning_tutorial.ipynb`) containing 20 code cells, 12 figures, the `PCA` + `KNeighborsClassifier` denoising workflow, and high-dimensional `PCA` + clustering pipelines.

## Run the companion notebook

Extract `student.zip` and run from its folder with Python 3.10+:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab unsupervised_learning_tutorial.ipynb
```
