A 35-minute teaching route

  1. Recursive splitting (7 min). Use the default training set to grow X₁ → X₂ splits; switch to X₂ → X₁ or redraw a noisy training sample. Inspect candidate RSS and trace one sample through the tree.
  2. Classification criteria (6 min). Switch Gini ↔ entropy on the disagreement example. Then try the error plateau dataset.
  3. Pruning (7 min). Increase α and explain the weakest link. Switch to cross-validation and compare the minimum-CV and one-SE choices.
  4. Boosting microscope (7 min). Compute one residual update. Then contrast it with one binary AdaBoost weight update.
  5. Ensemble comparison (8 min). Change B, noise and shrinkage. Explain the train–test gap and the effect of correlated trees.

What is live? Toy-tree construction, candidate scores, weakest-link pruning and boosting steps are computed in your browser. The larger ensemble and CV experiments were fitted in sklearn; their fixed predictions are embedded in this file.

Conventions. Binary splits use Xⱼ < s (left) and Xⱼ ≥ s (right). Entropy uses log₂; AdaBoost uses natural logs. Ties in the toy split search use feature index then threshold; binary leaf ties predict class 0. Only positive-gain splits are grown. Toy examples are synthetic.

Two distinctions for Lecture 6. Fitting regression residuals is squared-error gradient boosting. The AdaBoost microscope uses α = ½ ln((1−ε)/ε) and a symmetric weight update; the equivalent “update only mistakes” formulation uses twice that coefficient. A previously used stump is eligible again.

Experiment settings. Fixed seed 3612; 160 training and 1,000 test cases; two moons features. Averaging ensembles use deep trees. RF / Extra Trees inspect one randomly selected feature per node. AdaBoost uses stumps; gradient boosting uses depth-2 trees. These are illustrative choices, not an equal-compute or optimally tuned benchmark.
