Part A. Multiple Choice

Question 1

Why is logistic regression generally preferred over linear regression for estimating P(Y=1|X) in a binary classification problem?

  1. Linear regression cannot use continuous predictors.
  2. Linear regression may produce predicted probabilities below 0 or above 1.
  3. Logistic regression always has a nonlinear decision boundary.
  4. Logistic regression does not require parameter estimation.
Answer: B Logistic regression maps the linear predictor through the sigmoid function, so the estimated probability is always between 0 and 1.
Lecture 3.1: Classification and LR, slides 12–20.
Question 2

For logistic regression, if log(p/(1-p)) = 0, what is p?

  1. 0
  2. 0.25
  3. 0.5
  4. 1
Answer: C A log-odds value of 0 means the odds are 1, so p/(1-p)=1, giving p=0.5.
Lecture 3.1, slides 19–20.
Question 3

For a binary logistic regression classifier using a threshold of 0.5, which equation defines the decision boundary?

  1. β₀ + βᵀx = 1
  2. β₀ + βᵀx = 0
  3. p(x) = 0
  4. βᵀx = 0.5
Answer: B At threshold 0.5, the log-odds equal 0, so the linear predictor is 0.
Lecture 3.1, slides 28–30.
Question 4

In the credit-card example, why can the coefficient for student change from positive in a one-predictor model to negative after balance is added?

  1. Logistic regression cannot handle more than one predictor.
  2. Students tend to have higher balances, which confounds the marginal relationship.
  3. The sigmoid function changes when more predictors are added.
  4. The class labels have been reversed.
Answer: B Students tend to have higher balances, and balance is strongly related to default. Conditioning on balance can therefore reverse the marginal association.
Lecture 3.1, slides 25–27.
Question 5

Which property must hold for the output probabilities of a K-class softmax model?

  1. Each probability must be larger than 0.5.
  2. All probabilities must be equal.
  3. The probabilities must sum to 1.
  4. Only one class can have a coefficient vector.
Answer: C Softmax normalizes the exponentiated class scores so that the class probabilities sum to 1.
Lecture 3.1, slides 47–50.
Question 6

What does a generalized linear model make linear?

  1. The observed response Y itself.
  2. A link-function transformation of the conditional mean E[Y|X].
  3. The variance of Y.
  4. The probability density of every response distribution.
Answer: B A GLM uses a link function g so that g(E[Y|X=x]) = β₀ + βᵀx.
Lecture 3.2: Generalized Linear Models, slides 4–6.
Question 7

You want to predict the number of hospital visits in one year. Which model/link combination is the natural choice in the slides?

  1. Gaussian response + identity link
  2. Binomial response + logit link
  3. Poisson response + log link
  4. Poisson response + identity link
Answer: C Counts such as hospital visits are presented as Poisson outcomes, with a natural-log link for the conditional mean.
Lecture 3.2, slide 7.
Question 8

Which statement best distinguishes logistic regression from LDA?

  1. Logistic regression models P(X|Y), while LDA directly models P(Y|X).
  2. Logistic regression directly models P(Y|X), while LDA models P(X|Y) and uses Bayes' theorem.
  3. Both estimate exactly the same quantities in exactly the same way.
  4. LDA cannot output class probabilities.
Answer: B Logistic regression is presented as discriminative learning; LDA is generative and models class-conditional feature distributions before applying Bayes' theorem.
Lecture 3.3: LDA and Evaluation, slides 8–13 and 36.
Question 9

What covariance assumption defines standard multivariate LDA in these slides?

  1. Every class has the same mean.
  2. Every class has its own unrelated covariance matrix.
  3. Classes have different means but share a common covariance matrix.
  4. All predictors must be conditionally independent.
Answer: C LDA assumes class-specific means but a common covariance matrix across classes.
Lecture 3.3, slides 22, 28 and 32.
Question 10

If two classes have similar class-conditional densities at x, but class 2 has a larger prior probability than class 1, what does LDA tend to do?

  1. Favor class 1.
  2. Favor class 2.
  3. Ignore the prior probabilities.
  4. Automatically switch to QDA.
Answer: B Bayes classification compares terms proportional to πₖ fₖ(x). A larger prior increases the posterior support for that class.
Lecture 3.3, slides 12–16.
Question 11

What changes when moving from LDA to QDA?

  1. QDA assumes identical class means.
  2. QDA allows a different covariance matrix for each class.
  3. QDA assumes all predictors are independent.
  4. QDA no longer uses Bayes' theorem.
Answer: B With class-specific covariance matrices, quadratic terms remain in the discriminant functions, producing quadratic decision boundaries.
Lecture 3.3, slides 32–34.
Question 12

What is the key simplifying assumption of Naive Bayes in the slides?

  1. All classes have equal priors.
  2. Features are conditionally independent given the class.
  3. Every decision boundary is quadratic.
  4. Every predictor must follow the same marginal distribution.
Answer: B Naive Bayes factorizes the class-conditional density into one-dimensional feature densities by assuming conditional independence.
Lecture 3.3, slides 32 and 35–41.
Question 13

Only 100 out of 1,000,000 emails are spam. A classifier predicts every email as non-spam. Which statement is correct?

  1. Accuracy is low and spam recall is high.
  2. Accuracy is very high but spam recall is zero.
  3. Both accuracy and spam recall are very high.
  4. Spam precision must equal one.
Answer: B Almost every email is correctly labeled as non-spam, giving very high accuracy, but no true spam is detected, so recall for the positive class is 0.
Lecture 3.3, slides 44–47.
Question 14

Sensitivity is equivalent to which quantity?

  1. Precision
  2. Specificity
  3. Recall / True Positive Rate
  4. False Positive Rate
Answer: C Sensitivity is TP/(TP+FN), which is the same as recall or the true positive rate.
Lecture 3.3, slides 46 and 51.
Question 15

A disease-screening classifier predicts positive when P(Y=1|X) ≥ t. If missing a positive case is very costly, what should generally happen to t?

  1. Increase t.
  2. Decrease t.
  3. Keep t fixed at 0.5 because 0.5 is always optimal.
  4. Set t greater than 1.
Answer: B Lowering the threshold makes the classifier predict positive more often, which generally reduces the false-negative rate and increases sensitivity.
Lecture 3.3, slides 52–53.
Question 16

What are the two axes of an ROC curve?

  1. Precision versus Recall
  2. True Positive Rate versus False Positive Rate
  3. Accuracy versus Threshold
  4. False Negative Rate versus True Negative Rate
Answer: B The ROC curve plots TPR (sensitivity/recall) against FPR (1 − specificity) as the classification threshold varies.
Lecture 3.3, slide 54.
Question 17

As the binary classification threshold becomes very low, toward which region of the ROC plot do we generally move?

  1. Bottom-left
  2. Top-right
  3. Exactly the center
  4. The threshold does not affect the ROC operating point
Answer: B A very low threshold predicts many observations as positive, so both TPR and FPR tend to become large.
Lecture 3.3, slides 52–54.
Question 18

If recall is more important than precision in the Fβ score, which relationship should β satisfy?

  1. β < 1
  2. β = 0
  3. β > 1
  4. β has no effect on the balance between precision and recall
Answer: C In the slides, β > 1 places relatively more weight on recall, while β < 1 favors precision.
Lecture 3.3, slides 48–49.

Part B. True / False

Question 19

True or False: In logistic regression, the probability P(Y=1|X) itself is assumed to be a linear function of X.

  1. True
  2. False
Answer: False The log-odds are linear in X; the probability is obtained by applying the inverse-logit (sigmoid) function.
Lecture 3.1, slides 19–21.
Question 20

True or False: Decreasing the classification threshold generally decreases both the false positive rate and the false negative rate.

  1. True
  2. False
Answer: False Lowering the threshold generally reduces false negatives but increases false positives; this trade-off is why the threshold matters.
Lecture 3.3, slides 52–54.
