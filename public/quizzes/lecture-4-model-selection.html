Part A. Multiple Choice

Question 1

A team uses 5-fold cross-validation to compare ridge penalties. Before making the folds, it standardizes every predictor using the mean and standard deviation of the entire dataset. What is the main problem?

  1. The ridge objective can no longer be optimized.
  2. Information from each validation fold influences its own preprocessing, making the CV estimate optimistic.
  3. Standardization forces all ridge coefficients to be zero.
  4. Five-fold CV may only be used with unscaled predictors.
Answer: B Cross-validation should evaluate the whole learning procedure. The scaler must be fitted on each training fold and then applied to that fold's validation data; otherwise the held-out data leak into model preparation.
Lecture 4.1, slides 27 and 31; Lecture 4.2, slides 5-6.
Question 2

Five-fold CV selects a degree-3 polynomial model. Which action should normally follow?

  1. Keep the one fold-specific model with the smallest validation error.
  2. Average the five coefficient vectors and deploy the average.
  3. Discard the fold-specific fits and refit the selected degree-3 procedure on all available training data.
  4. Choose degree 5 because five folds were used.
Answer: C The fold-specific fits estimate the performance of a procedure. Once the procedure is selected, it is trained again using the full training dataset.
Lecture 4.1, slides 30-31.
Question 3

Two researchers use different random 50/50 training-validation splits and obtain noticeably different validation errors. Which explanation best matches the lecture?

  1. A single validation estimate can be highly variable, and models fitted on only half the observations may perform worse than a final model fitted on all observations.
  2. The test error of any model is undefined unless LOOCV is used.
  3. Validation error must always underestimate the error of the model fitted on all data.
  4. The two researchers must have used different response variables.
Answer: A A single split depends strongly on which observations land in each part. Because fewer observations are used for fitting, its error may also overestimate the error of the final all-data fit.
Lecture 4.1, slide 26.
Question 4

At the same test point, Model A has squared bias 4 and variance 9, while Model B has squared bias 9 and variance 2. Assume both face the same irreducible error. Which model has lower expected test MSE at that point?

  1. Model A, because its bias is lower.
  2. Model B, because 9 + 2 is smaller than 4 + 9.
  3. They are equal because bias and variance always offset exactly.
  4. It cannot be compared without knowing the training MSE.
Answer: B Ignoring the common irreducible error, Model A contributes 13 and Model B contributes 11. Lower bias alone does not guarantee lower test MSE.
Lecture 4.1, slides 18-23.
Question 5

Only 5% of observations belong to the positive class. Why is stratified 5-fold CV usually preferable to an ordinary random split into folds?

  1. It makes every fold contain exactly the same observations.
  2. It approximately preserves the class proportions in each fold, reducing the chance of unrepresentative validation folds.
  3. It guarantees identical fitted coefficients across folds.
  4. It converts the classification task into regression.
Answer: B Stratification keeps each fold's target-class mix close to that of the complete dataset, which is especially useful for imbalanced classification.
Lecture 4.1, slide 29.
Question 6

The same predictor is recorded once in dollars and once in thousands of dollars. With no standardization, why can ridge regression produce different fitted results after this unit change?

  1. Ridge penalizes residuals rather than coefficients.
  2. The numerical scale changes the coefficient required for the same prediction and therefore changes its contribution to the penalty.
  3. Ordinary least squares is also never invariant to a change of units.
  4. The intercept is always multiplied by the predictor's unit.
Answer: B Ridge penalizes coefficient magnitudes. Rescaling a predictor changes the coefficient magnitude needed to represent the same effect, so predictors should usually be standardized first.
Lecture 4.1, slide 39.
Question 7

Starting from λ = 0, suppose the ridge penalty is gradually increased. Which pattern is most consistent with the lecture?

  1. Bias tends to decrease, variance tends to increase, and coefficients move away from zero.
  2. Bias tends to increase, variance tends to decrease, and coefficients move toward zero.
  3. Both bias and variance must decrease monotonically.
  4. The fit remains identical to ordinary least squares for every finite λ.
Answer: B At λ = 0, ridge equals OLS. Stronger regularization shrinks coefficients, typically trading higher bias for lower variance.
Lecture 4.1, slide 43.
Question 8

You have 200 standardized predictors and believe only a small subset is useful. You also want the fitted model itself to remove irrelevant predictors. Which method most directly targets this goal?

  1. Ridge regression, because every finite penalty makes many coefficients exactly zero.
  2. Lasso regression, because its L1 penalty can yield sparse coefficient estimates.
  3. Ordinary least squares, because it automatically performs subset selection.
  4. Row normalization, because it deletes low-variance columns.
Answer: B Lasso performs shrinkage and automatic variable selection by allowing some coefficients to be exactly zero.
Lecture 4.1, slides 45 and 48.
Question 9

Several genuinely useful predictors are strongly correlated. You want shrinkage but prefer the group to be retained together rather than having one predictor selected somewhat arbitrarily. Which choice is most appropriate?

  1. Pure lasso
  2. Elastic Net
  3. Univariate min-max scaling
  4. Leave-one-out cross-validation without regularization
Answer: B Elastic Net combines L1 and L2 penalties and is useful when predictors are correlated; compared with pure lasso, it is more likely to retain correlated predictors together.
Lecture 4.1, slide 50.
Question 10

There are n = 80 observations and p = 500 predictors. Which statement about stepwise subset selection is best?

  1. Backward selection is natural because the full least-squares model is always available.
  2. Forward selection can still be used, while backward selection cannot start from a uniquely fitted full least-squares model.
  3. Best subset selection is easy because n is small.
  4. Neither forward nor backward selection depends on the relation between n and p.
Answer: B Backward selection requires fitting the full model and therefore requires n > p in this treatment. Forward selection starts with no predictors and remains viable when n < p.
Lecture 4.1, slide 61.
Question 11

Forward stepwise selection returns a four-predictor model. What can be concluded about it?

  1. It must be the globally best four-predictor model among all possible subsets.
  2. It is the best model along the greedy sequence considered, but a different four-predictor subset may fit better.
  3. It must match the four-predictor model chosen by lasso.
  4. It has evaluated all 2p possible subsets.
Answer: B Stepwise methods search a restricted, greedy path. They are computationally cheaper than best subset selection but are not guaranteed to find the global best subset of a given size.
Lecture 4.1, slides 58-61.
Question 12

A nominal feature Color has values red, green, and blue, with no natural order. Which representation avoids imposing an artificial ranking?

  1. red = 0, green = 1, blue = 2 in a single column
  2. Three one-hot binary columns
  3. The z-score of each color name
  4. The L2 norm of the category label
Answer: B One-hot encoding represents each category with its own binary indicator. A single integer-coded column can suggest an ordering or spacing that is not present.
Lecture 4.2, slide 11.
Question 13

A data matrix contains one row per document and one column per word count. Which operation matches normalization as defined in the lecture?

  1. Center each word column and divide by its standard deviation.
  2. Scale each document row to have unit L1 or L2 norm.
  3. Map every column independently to the interval [0, 1] only.
  4. Replace every missing entry with the column mean.
Answer: B The lecture distinguishes feature-wise standardization (columns) from sample-wise normalization (rows) to unit norm.
Lecture 4.2, slides 6 and 10.
Question 14

A second-degree expansion of two predictors includes x₁, x₂, x₁², x₁x₂, x₂². Which term lets the effect of x₁ depend on the value of x₂?

  1. x₁
  2. x₁²
  3. x₁x₂
  4. x₂²
Answer: C The product term is an interaction: changing x₂ changes the slope associated with x₁.
Lecture 4.2, slides 15-16.
Question 15

Why can a polynomial regression such as y = β₀ + β₁x + β₂x² + ε still be fitted with linear regression machinery?

  1. Its fitted curve must be a straight line in x.
  2. It is linear in the unknown coefficients after the polynomial features are constructed.
  3. The squared feature is treated as a new response variable.
  4. Polynomial regression contains no tuning choices and cannot overfit.
Answer: B The relationship can be nonlinear in the input while remaining linear in β₀, β₁, β₂.
Lecture 4.2, slide 16.
Question 16

Consider y = β₀ + f₁(x₁) + f₂(x₂) + ε. Which statement best describes this GAM?

  1. Each predictor may have a nonlinear effect, while the additive structure allows the effects to be inspected separately.
  2. The model automatically represents every possible interaction between x₁ and x₂.
  3. Both f₁ and f₂ must be straight lines.
  4. Additivity guarantees zero training and test error.
Answer: A A classical GAM combines flexible univariate effects additively. That makes each effect easier to visualize, but arbitrary interactions require additional terms.
Lecture 4.2, slides 21-22.

Part B. True / False

Question 17

True or False: For a finite positive value of λ, ridge regression will typically set some predictor coefficients exactly to zero.

  1. True
  2. False
Answer: False Ridge usually shrinks all coefficients toward zero without making them exactly zero. Exact sparsity is the characteristic emphasized for lasso.
Lecture 4.1, slide 45.
Question 18

True or False: If each non-constant feature is z-score standardized, its mean becomes approximately zero and its standard deviation becomes one, but the transformation does not by itself make a skewed distribution Gaussian.

  1. True
  2. False
Answer: True Z-score standardization changes location and scale. It does not generally change the distributional shape.
Lecture 4.2, slides 6-7.
